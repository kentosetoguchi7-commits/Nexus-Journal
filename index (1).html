Features

FAQ

Questions, answered

Do I need an account or to sign up?

No. Open the journal and start logging. There is nothing to sign up for and no password to remember.

Where are my trades stored?

Only in the browser on your device. Nothing is uploaded, so nobody else can see your trades. Use Settings → Download backup now and then, and restore that file on any other computer.

Which brokers can I import from?

Tradovate (Performance report) and NinjaTrader (Trades tab) are detected automatically. Any other platform that exports a list of round-trip trades works by matching the columns once.

Which contracts are supported?

ES, MES, NQ, MNQ, YM, MYM, RTY, M2K, CL, MCL, GC, MGC, SI, ZN, ZB and 6E come set up with point values and commissions. You can add any other contract in Settings.

Does it work on my phone?

Yes, it works in any modern browser on phone, tablet or computer. Each device keeps its own copy, so use backups to move your journal between them.
